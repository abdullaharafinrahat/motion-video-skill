# 09 — QA and delivery

**Blacklist reminder (CORE §5):** glow · purple gradients · card-in-card · glass blur · one easing for all · Ken Burns ·
meaningless decoration · bounce · emoji/icon grids · template layout · text/faces in generated images · gradient text ·
default fonts · invented data · filler motion. Also check everything in `blacklist-extra.md`.

Do all checks before showing the user anything. Write results to `qa-report.md`. Fix, then re-run; do not just report failures you could fix.

## 1. Code lint (hard gate)
`python tools/lint_blacklist.py .` → exit code 0. No exceptions, no edits to the linter.

## 2. Automated frame checks (sample every 0.5 s + first/last frame of each beat)
- **Black/frozen frames:** mean luma < 5 for > 2 frames, or identical consecutive frames outside planned holds.
- **Text overflow & safe zones:** in the browser, for each text element `getBoundingClientRect()` must sit inside the safe area and the frame.
- **Contrast:** WCAG ratio ≥ 4.5 (≥ 3 for huge type) between text colour and the sampled background behind it.
- **Glyph coverage:** every character on screen exists in the chosen font's `cmap` (fontTools); no tofu boxes. View one frame per script.
- **Reading time:** each text lasts ≥ 0.25 s per word + 0.4 s.
- **Language check:** every on-screen string is in the input language (no stray English from templates/placeholders).
- **Facts check:** every number on screen maps to a `facts` entry with a source.

## 3. Audio checks
Duration equals video ± 1 frame; measured loudness near −14 LUFS; true peak ≤ −1 dBTP; no unintended silence > 1.5 s;
SFX onsets within ± 1 frame of their visual `hits`; VO survives mono sum.

## 4. Vision review (you view the frames)
Open the contact sheet of the final video (every 1 s) and also the first 3 seconds at full size. For **each beat** answer:
1. Can I state why this is here in one sentence (matches `why`)?
2. Is the asset clearly relevant to the speech at this moment?
3. Does anything match a blacklist item (§5 and extra)? Look for: glow, purple gradients, nested containers, uniform motion, uniform layouts.
4. Is hierarchy clear in 1 second (what do I read first)?
5. Is the motion varied across neighbouring beats (not the same entrance/camera repeated)?
If any answer is no → fix the beat, re-render only that beat, re-check.

## 5. Talking-video extras
Matte flicker and edges at 100% on 5 frames; lip-sync at 3 points (visible mouth closure vs audio plosive); jump cuts hidden by framing changes.

## 6. Deliver
Give the user: `out/final.mp4`, a short summary (length, resolution, language, energy arc, fonts, asset sources + licences from the manifest),
the QA result (what passed, what is a known limitation or fallback), and an offer to revise by beat ID.
Update `PROJECT.md` stage = done. Never claim a check you did not run.
